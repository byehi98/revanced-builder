# Third-party app icons

**These icons are not part of this project and are not covered by its licence.**

Each file is the launcher icon of the app it identifies and is the property of
that app's developer. It may be a registered or unregistered trademark. The
icons are shown only to identify which app a build belongs to; no affiliation,
sponsorship, or endorsement is claimed or implied.

Files are 96×96 PNGs cut to a circle, matching how a round launcher displays
them. Most come from the app's Google Play listing at `=s96-cc`. Apps that are
not on Play use the launcher icon extracted from the built APK instead.

`../icons/sources.json` records the origin of every file. To refresh or add
icons, run `python3 scripts/fetch_icons.py` from the repository root.
